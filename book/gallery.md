## Add a gallery image

Use the following pattern when adding a photo:

```markdown
![Students exploring biomechanics at National Biomechanics Day](figures/gallery/national-biomechanics-day-2026.jpg)

_Students exploring biomechanics at National Biomechanics Day, 2026._
```

Please confirm that everyone pictured has permission for the image to be shared publicly before uploading it. Include photographer or source information in the caption when appropriate.
